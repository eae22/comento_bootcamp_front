# comento_bootcamp_front

코멘토 프론트엔드 직무부트캠프 과제 레포입니다.  
**업무 요청서 → 개발 → 문서화 → 피드백 반영** 흐름으로 4주 동안 과제를 진행했습니다.

## 🫣 이 레포에서 볼 수 있는 것
- 주차별 요구사항을 바탕으로 만든 **웹 페이지 결과물**
- 피드백을 반영하며 개선한 **코드**

## 🖇️ 진행 방식
- 매주 과제는 **업무 요청서** 형태로 제공됨
- 결과물은 **GitHub 링크 + (필요 시) 문서**로 제출
- 2주차, 4주차에 발표 진행
- 제출 후 **1~2일 이내 피드백(PPT)** 수령 → 다음 과제에 반영

## 🕹️ 사용 기술
- HTML / CSS / JavaScript (Vanilla)

## 📂 폴더 구조
- `week1` : 자기소개 페이지
- `week2` : 자판기 레이아웃 과제(정적 화면 UI)
- `week3` : 이벤트 있는 웹페이지 2개
  - `project1` : 시계(배터리/알람/추가 기능)
  - `project2` : 계산기(연산/기록/초기화/추가 기능)
- `week4` : 최종 프로젝트 2개
  - `project1` : To-do-List(일정 추가/삭제)
  - `project2` : 회원가입(아이디 중복확인/비밀번호 규칙 검증)

## 🔜 실행 방법
각 프로젝트 폴더의 `index.html`을 실행하면 됩니다.

예)
- `week1/index.html`
- `week3/project2/index.html`

## 🧹 과제 요약
- **Week1**: 자기소개 페이지 제작
- **Week2**: 자판기 레이아웃 설계 연습(기능 구현 X)
- **Week3**: DOM 이벤트/상태 처리 중심 프로젝트 2개 + 문서화
- **Week4**: 요구사항 기반 기능 구현 + 문서화
