# Project#2 회원가입

## 프로젝트 개요

HTML/CSS/JavaScript로 구현한 간단한 회원가입 웹 페이지입니다.  
사용자는 **아이디 중복 확인**과 **비밀번호 규칙 검증**을 통과한 경우에만 회원가입을 완료할 수 있습니다.  
DOM 요소 캐싱, 이벤트 분리(입력/클릭/제출), 상태(State) 기반 UI 제어를 통해 기본적인 회원가입 폼 검증 흐름을 연습하는 프로젝트입니다.

> 본 프로젝트는 서버/DB 연동 없이, 브라우저 내 상태(State.users 배열)에 사용자 정보를 저장하는 방식으로 동작합니다.

## 주요 기능

- 아이디 입력 검증 (영문/숫자, 4~12자)
- 아이디 중복 확인 기능
- 비밀번호 규칙 검증
  - 8자 이상
  - 대문자/숫자/특수문자 각각 1개 이상
- 비밀번호 확인 일치 여부 검증
- 비밀번호 보기/숨기기 토글
- 조건 충족 시에만 회원가입 버튼 활성화
- 회원가입 성공 시 알림창(alert) + 폼 초기화

## 설치 방법

별도의 설치 과정 없이 실행 가능합니다.

1. 프로젝트 다운로드 또는 클론
2. 아래 파일 구조를 유지한 상태로 `index.html`을 실행

## 사용 방법

1. 아이디를 입력한 뒤 **중복확인** 버튼을 눌러 중복 여부를 확인합니다.
2. 비밀번호를 입력하면 규칙 충족 여부가 안내 문구로 표시됩니다.
3. 비밀번호 확인에 동일한 값을 입력하면 일치 여부가 표시됩니다.
4. 모든 조건을 만족하면 **회원가입** 버튼이 활성화됩니다.
5. 회원가입 완료 시 알림창이 출력되고 폼이 초기화됩니다.

### 입력 규칙

- 아이디: 영문/숫자만 가능, 4~12자
- 비밀번호: 8자 이상 + 대문자/숫자/특수문자 각각 1개 이상 포함
- 비밀번호 확인: 비밀번호와 동일해야 함
