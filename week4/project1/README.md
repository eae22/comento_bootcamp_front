# Project#1 To-Do List

## 프로젝트 개요

HTML/CSS/JavaScript로 구현한 간단한 To-Do List 웹 페이지입니다.  
사용자는 할 일을 **추가/완료 처리/삭제**할 수 있으며, 목록 영역에서 **전체 개수와 완료 개수**를 확인할 수 있습니다.  
DOM 요소 캐싱, 이벤트 위임, 상태(State) 기반 렌더링 구조로 기본적인 프론트엔드 앱 구조를 연습하는 프로젝트입니다.

## 주요 기능

- 일정 추가
- 입력값 검증 (빈 값 방지, 50자 제한)
- 완료/미완료 토글
- 일정 삭제
- 전체/완료 개수 카운트 표시

## 설치 방법

별도의 설치 과정 없이 실행 가능합니다.

1. 프로젝트 다운로드 또는 클론
2. 아래 파일 구조를 유지한 상태로 `index.html`을 실행

## 사용 방법

1. 입력창에 일정을 작성한 뒤 **추가** 버튼을 누릅니다.
2. 리스트에서 체크 버튼을 누르면 **완료/미완료**가 토글됩니다.
3. **삭제** 버튼을 누르면 확인창이 뜨며, 확인 시 해당 일정이 삭제됩니다.
4. 상단에 **전체/완료 개수**가 자동으로 갱신됩니다.

### 입력 규칙

- 공백만 입력한 경우: `일정을 입력해주세요.`
- 50자 초과 입력: `일정은 50자 이내로 입력해주세요.`
