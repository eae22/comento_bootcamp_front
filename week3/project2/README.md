# Project#2 계산기

## 프로젝트 개요

HTML/CSS/JavaScript로 구현한 간단한 계산기 웹 페이지입니다.  
숫자/연산자 입력 흐름을 화면에 표시하고, `=` 버튼을 통해 연산 결과를 출력합니다.  
연산 기록(History) 표시 및 초기화 기능을 포함하여, DOM 이벤트 처리와 입력 흐름을 연습하는 프로젝트입니다.

## 주요 기능

- 숫자 키패드(0~9, '00', '.') 및 사칙연산(+, -, *, /) 버튼
- 입력 중인 식 표시 + 마지막 결과 표시
- `=` 버튼: 결과 출력
- 연산 기록(History) 저장 및 최근 10개 표시
- 초기화 기능
    - `C`: 전체 초기화
    - `CE`: 한 글자 삭제
- 전체 기록 삭제 버튼: 연산 기록 초기화

1. 프로젝트 다운로드 또는 클론
2. 아래 파일 구조를 유지한 상태로 `index.html`을 실행

## 사용 방법

1. 숫자 키패드 및 사칙연산 버튼을 눌러 식을 입력합니다.
2. `=` 버튼을 누르면 결과가 출력되며, 연산 기록에 저장됩니다.
3. `C`는 전체 초기화, `CE`는 마지막 한 글자를 삭제합니다.
4. 전체 기록 삭제 버튼을 누르면 연산 기록이 초기화됩니다.

### 입력 규칙 / 예외 처리

- 소수점(`.`)은 **현재 숫자 토큰에 1개만** 입력 가능합니다.
- 연산자를 연속 입력하면 **마지막 연산자로 교체**됩니다.
- 식이 올바르지 않으면 결과 영역에 `Error`가 표시됩니다.
- 0으로 나누는 등 계산 결과가 무한대인 경우 `Infinity`로 처리됩니다.
