# Project#1 시계

## 프로젝트 개요

HTML/CSS/JavaScript로 구현한 디지털 시계 웹 페이지입니다.  
배터리가 **1초마다 1%씩 감소**하며, 배터리가 0%가 되면 시계 화면이 **OFF**됩니다.  
사용자는 시/분/초를 입력해 **알람을 최대 3개까지 추가/삭제**할 수 있습니다.  
DOM 요소 캐싱, 이벤트 처리, 타이머 흐름을 연습하는 프로젝트입니다.

## 주요 기능

- 배터리 표시 (시작 100%)
- 배터리 1초마다 1% 감소
- 배터리 0% 시 시계 화면 OFF 처리
- 알람 추가/삭제 (최대 3개)
- 알람 현황 표시
- 추가 기능 1개 (예: 배터리 충전 버튼 +20%)

## 설치 방법

별도의 설치 과정 없이 실행 가능합니다.

1. 프로젝트 다운로드 또는 클론
2. 아래 파일 구조를 유지한 상태로 `index.html`을 실행

## 사용 방법

1. 페이지 실행 시 배터리가 100%에서 시작하며 1초마다 감소합니다.
2. 배터리 0%가 되면 시간 표시가 중단됩니다.
3. 알람 입력 영역에 **시/분/초**를 입력한 뒤 **추가** 버튼을 누르면 알람이 등록됩니다.
4. 등록된 알람은 최대 3개까지 표시되며, **삭제** 버튼으로 제거할 수 있습니다.
5. 추가 기능 버튼(예: 배터리 충전 +20%)을 누르면 배터리가 20%만큼 회복됩니다.

### 입력 규칙
- 시/분/초는 숫자 입력 + 범위 검증(시: 0~23, 분/초: 0~59) 후 등록됩니다.
- 알람은 중복 불가이며 최대 3개까지 등록 가능합니다.
